# Courses API — React Frontend

A React application that provides a browser-based interface for the Courses API.

## Overview
The frontend supports course-related user interactions and communicates with the Spring Boot backend. The components and service layer define the exact screens and workflows.

## Related Project
- [Courses API Spring Boot Backend](https://github.com/MahiTzy/course-api-springboot)

## Technology
- React
- JavaScript
- CSS
- Node.js and npm

## Prerequisites
- Node.js (LTS recommended)
- npm
- Running Courses API backend

## Getting Started
```bash
git clone https://github.com/MahiTzy/course-ui-react.git
cd course-ui-react
npm install
```
Start the frontend using the script defined in `package.json` (commonly `npm start` or `npm run dev`).

## Configuration
Review the API service configuration and set the backend base URL for your local environment. Do not expose secrets in client-side configuration.

## Development
Run the backend and frontend together to test integrated course workflows. Use the browser developer tools to inspect API requests and errors.
